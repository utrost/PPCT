PPCT Web Generator

Generate an A4 PlotPen Characterization Target SVG without installing Python. The SVG has two layers: a printable template layer and a plot-data layer.

Print the template at 100%. Do not fit to page. Then plot the data layer on top.

Sheet metadata

Leave this on for a two-layer SVG. Turn it off for a plot-data-only SVG when your plotting software cannot hide layers.
